# Lina Olivetree

Lina Olivetree is a Vite + React storefront and journal experience for a creative brand centered on illustrated products and reforestation. The site presents a product collection, a mission page, journal entries, and detail pages for individual products and posts.

## Getting Started

### Prerequisites

- Node.js 18+ recommended
- npm

### Install

```bash
npm install
```

### Run the app

```bash
npm run dev
```

The Vite dev server runs on `http://localhost:3000`.

## Available Scripts

- `npm run dev` starts the local development server
- `npm run build` creates a production build in `dist/`
- `npm run preview` serves the production build locally
- `npm run lint` runs TypeScript type-checking with `tsc --noEmit`
- `npm run clean` removes the `dist/` directory
